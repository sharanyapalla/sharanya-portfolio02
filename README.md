# P. Sharanya | Portfolio

Personal portfolio website of **P. Sharanya**, B.E. Electronics and Communication Engineering (ECE) student at Prathyusha Engineering College (2024-2028).

Built with plain **HTML and CSS** (no frameworks, no JavaScript).

## Sections
Home, About, Skills, Projects, Internship, Certifications, Contact.

## Run locally
1. Download or clone this repository.
2. Open `index.html` in any modern browser.

## Project structure
```
sharanya-portfolio/
├── index.html    # page content
├── style.css     # all styling
├── .nojekyll     # tells GitHub Pages to serve files as they are
├── .gitignore
└── README.md
```
